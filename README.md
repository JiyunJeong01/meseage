# 원형 이미지 + NOTICE 홈페이지

## 미리보기
`index.html`을 브라우저로 열면 됩니다. `obalie.png`는 반드시 같은 폴더에 두세요.

## 수정
`index.html`의 `<h1>`, `.subtitle`, `<li>` 내용을 원하는 문구로 수정하세요.

## GitHub Pages 배포
1. GitHub에서 Public 저장소를 만듭니다.
2. `index.html`과 `obalie.png`를 저장소 최상위에 업로드하고 Commit합니다. (ZIP 파일 자체를 올리는 게 아닙니다.)
3. Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 선택하고 Save를 누릅니다.
5. 배포 후 `https://사용자이름.github.io/저장소이름/`에서 확인합니다.
